Location Scout

Open a business website or a map listing, click the toolbar icon, and get a quick read on whether that kind of place tends to work for a vending machine.

How to get it Source code on GitHub

What it does

  • Reads the business name, ZIP and type from the one page you are on, only when you click the icon.
  • Gives a short fit note for that kind of venue and two things to check before you pitch.
  • Opens VendBuddy's Lead Finder pre-filled with the venue type and ZIP, so you can find the person who approves placements.

Privacy by design

  • Manifest V3 with two permissions only: activeTab and scripting.
  • No background worker, no stored data, no analytics and no network calls from the extension itself.
  • All code ships inside the package, so you can read exactly what runs. Links open vendbuddy.io in a new tab.

Full statement: VendBuddy privacy policy.

Get it

  • Chrome Web Store: listing link coming soon
  • Load it yourself: download the extension/ folder from the source repository, open chrome://extensions, switch on Developer mode, choose Load unpacked and select the folder.

Like every extension, it cannot read chrome:// pages, the Web Store or PDFs. In those cases the popup lets you type the details in.

Using the fit notes well

A fit note is a starting point, not a verdict. Pair it with the location checklist, then read the matching guide: vending machine locations by business type and locations to avoid.
